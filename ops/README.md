# Ops Sandbox

This directory holds local or sandbox operational files that should not live at repository root.

## Current contents

- `sandbox/access.log` — local nginx access log placeholder
- `sandbox/build.log` — local build output captured during sandbox testing
- `sandbox/live_index.html` — local placeholder HTML used during sandbox checks
- `sandbox/nginx.211-ai.com.bootstrap.temp.conf` — temporary bootstrap nginx config snapshot
- `sandbox/nginx_test.conf` — local nginx test configuration
- `sandbox/nginx_test.log` — local nginx test output
- `sandbox/nginx_test.pid` — local nginx PID placeholder

These files remain tracked as historical sandbox references, but new operational scratch files should be added here instead of at repository root.
