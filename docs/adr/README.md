# Architecture Decision Records

This directory contains Architecture Decision Records (ADRs) for the 211-AI platform. ADRs are stable, canonical documents that record significant design and architectural decisions.

| Document | Scope |
| --- | --- |
| `WALLET_PRODUCTION_DECISIONS_ADR.md` | Wallet production decision log |
| `WALLET_SECURITY_ARCHITECTURE_ADR.md` | Wallet security architecture decisions |

ADRs in this directory are considered authoritative. They are not updated retroactively; new decisions append to the log rather than revise it.
